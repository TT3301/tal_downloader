- 范围：只修改源码和测试，不生成任何客户端安装包或可执行文件

## 已修复问题

1. 课节选择从“数组下标”改为缓存并传递服务端返回的真实课节对象，下载页不再重新拉取列表后按位置匹配。
2. 录像清晰度不再依赖 Go map 的随机遍历顺序，改为确定性选择最高可识别清晰度。
3. 延伸课程恢复 `task -> realRecordId -> resources` 的解析流程，不再拿普通课节的 `liveId` 强行请求延伸录像。
4. 分段下载校验 HTTP 状态和 `Content-Range`；服务端忽略 Range 时回退单线程，异常时删除不完整文件。
5. HLS 支持主播放列表、规范相对 URL、鉴权查询参数继承，并在任一媒体分片失败时让整个任务失败。
6. 下载器每次启动只消费本次待处理队列，避免返回课程页后再次启动时重复下载旧任务。
7. 修复下载错误字段和进度管理器的并发读写问题。
8. 将调班后遗留的同名、同科目、同课节数记录合并为一门逻辑课程，同时保留每个 `stdCourseId` 与 `tutorId`。
9. 合并课程以接口排序最靠前的记录为主来源；历史来源仅在 task 三元组、`liveId` 或双方唯一课节标题匹配时作为回退，不再按数组位置强行关联不同班级的课节。
10. 下载失败后的“继续”按钮现在会重新启动失败任务；暂停中的“继续”仍只恢复当前请求，避免把已经退出的失败协程误当成可恢复任务。
